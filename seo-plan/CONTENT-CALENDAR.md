## Rules

1. **Nothing generated in bulk.** The 148-page matrix came from a find-and-replace script. If a page cannot be written by hand, it should not exist.
2. **The swap test.** If a page reads identically with the city or amenity name swapped, it is a duplicate. Merge it.
3. **First-hand or not at all.** Route pages need someone who has driven the route. Landmark pages need someone who has been there.
4. **Every new page needs a home.** It is linked from a hub and links back before it is published. No more orphans.
5. **Refresh beats publish.** A rewritten page with rankings usually outperforms a new one without.
6. **No self-assigned ratings, ever.** Real reviews with `Review` schema, or nothing.
